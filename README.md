## About

This project is a hands-on exercise for practicing core Git and GitHub
workflows:

- Initializing a repository
- Making commits
- Creating and merging branches
- Pushing to a remote

The program itself is a small Python script that prints my name and
today's date, which is later extended with basic calculator functions.
